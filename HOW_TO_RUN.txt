🎨 MÀU SẮC CÓ NGHĨA GÌ?
════════════════════════════════════════════════════════════════════════════

✓ (xanh lá) = Test đã passed, thành công
✗ (đỏ)     = Test failed, thất bại
→ (xanh dương) = Request gửi đi
← (xanh dương) = Response nhận về
ℹ (xanh dương) = Thông tin

Nếu bạn thấy toàn ✓ = Tất cả test passed = SUCCESS! 🎉


❌ NẾUGAS LỖI
════════════════════════════════════════════════════════════════════════════

LỖI 1: "Cannot find module 'mysql2/promise'"
────────────────────────────────────────────
  Nguyên nhân: Dependencies chưa cài
  Cách sửa:
    cd d:\khoaluan\backend
    npm install

LỖI 2: "Port 8080 already in use"
────────────────────────────────────
  Nguyên nhân: Port 8080 đã bị chiếm
  Cách sửa:
    # Cmd mới
    netstat -ano | findstr :8080
    
    # Kết quả sẽ hiện số process (ví dụ: 1234)
    taskkill /PID 1234 /F
    
    # Rồi chạy lại backend

LỖI 3: "Cannot find ca.pem"
────────────────────────────
  Nguyên nhân: SSL certificate không có
  Cách sửa:
    1. Download ca.pem từ Aiven Dashboard
    2. Đặt vào: d:\khoaluan\backend\ca.pem

LỖI 4: "ECONNREFUSED"
─────────────────────
  Nguyên nhân: Backend không chạy
  Cách sửa:
    Hãy chắc chắn rằng Terminal 1 đang chạy:
    cd d:\khoaluan\backend && node server.js

LỖI 5: "Invalid token"
──────────────────────
  Nguyên nhân: JWT_SECRET không đúng
  Cách sửa:
    Kiểm tra file .env trong d:\khoaluan\backend\

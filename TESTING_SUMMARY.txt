🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: Backend không khởi động
  → Kiểm tra cổng 8080 có bị chiếm không
  → netstat -ano | findstr :8080
  → taskkill /PID <PID> /F

Problem: Database connection error
  → Kiểm tra file ca.pem trong d:\khoaluan\backend\
  → Verify .env credentials
  → Check Aiven Cloud Dashboard

Problem: JWT token invalid
  → Verify JWT_SECRET in .env
  → Check token format (Bearer <token>)
  → Token có thể hết hạn (1 ngày)

Problem: Port 3306 (MySQL) not accessible
  → Check firewall settings
  → Verify Aiven connection string in .env
  → Check DB_HOST, DB_PORT, DB_USER, DB_PASSWORD

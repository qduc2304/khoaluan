✨ VALIDATION FRAMEWORK
═══════════════════════════════════════════════════════════════════════════════

Created centralized validators.js with 9 functions:

validateEmail(email)
  └─ Checks email format using regex
     Rejects: no @, no domain, spaces, missing parts

validatePassword(password)
  └─ Checks password strength
     Requires: minimum 6 characters

validateFaculty(faculty)
  └─ Checks against TBU faculties
     Accepts: Only 4 official TBU faculties
     Optional: null/undefined

validateRole(role)
  └─ Checks against defined roles
     Validates: director, admin, specialist, instructor, student, council

validateScore(score)
  └─ Validates score range
     Range: 0-100 (integers)
     Optional: null/undefined

validateDateFormat(date)
  └─ Checks date format
     Format: YYYY-MM-DD only
     Optional: null/undefined

validateRequired(obj, fields)
  └─ Checks required fields present
     Rejects: empty strings, only whitespace

validateTopicStatus(status)
  └─ Checks topic status validity
     Valid: pending, approved, rejected, grading, completed

canScoreTopic(status)
  └─ Checks if topic can be scored
     Allows: approved, grading only

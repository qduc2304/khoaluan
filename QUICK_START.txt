                          TROUBLESHOOTING QUICK FIX
═══════════════════════════════════════════════════════════════════════════

❌ "Cannot find module 'mysql2/promise'"
   → cd d:\khoaluan\backend && npm install

❌ "Port 8080 already in use"
   → netstat -ano | findstr :8080
   → taskkill /PID [PID_NUMBER] /F

❌ "ECONNREFUSED - Cannot connect to backend"
   → Make sure Terminal 1 is running with: node server.js

❌ "Cannot find ca.pem"
   → Download from Aiven Dashboard
   → Put it in: d:\khoaluan\backend\ca.pem

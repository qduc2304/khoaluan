📋 ERROR CODES STANDARDIZED
═══════════════════════════════════════════════════════════════════════════════

AUTHENTICATION:
  NO_TOKEN                      - No authorization header
  INVALID_TOKEN_FORMAT          - Bearer format incorrect
  EMPTY_TOKEN                   - Bearer token is empty
  INVALID_TOKEN_PAYLOAD         - Token missing required fields
  TOKEN_EXPIRED                 - JWT token expired
  INVALID_TOKEN                 - JWT signature/format invalid
  AUTH_FAILED                   - Credentials incorrect
  INVALID_ROLE                  - User has no valid role

VALIDATION:
  MISSING_REQUIRED              - Required fields missing
  INVALID_EMAIL                 - Email format invalid
  INVALID_PASSWORD              - Password doesn't meet requirements
  INVALID_FACULTY               - Faculty not in TBU list
  INVALID_SCORE                 - Score outside 0-100 range
  INVALID_DATE                  - Date format not YYYY-MM-DD

AUTHORIZATION:
  INSUFFICIENT_PRIVILEGES       - User lacks required role
  UNAUTHORIZED                  - User lacks resource access
  NOT_ASSIGNED                  - Not assigned to this resource

DATA:
  MISSING_REQUIRED              - Required fields missing
  INVALID_INSTRUCTOR            - Instructor doesn't exist
  INVALID_CAMPAIGN              - Campaign doesn't exist
  TOPIC_NOT_FOUND               - Topic doesn't exist
  INVALID_TOPIC_STATUS          - Topic in wrong status for operation

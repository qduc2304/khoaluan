🚨 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Problem: Backend won't start
  Solution: Check if port 8080 is already in use
  $ netstat -ano | findstr :8080
  $ taskkill /PID <PID> /F

Problem: Database connection failed
  Solution: Check .env file in d:\khoaluan\backend\
  - Verify DB_HOST, DB_USER, DB_PASSWORD
  - Ensure ca.pem certificate exists

Problem: JWT token invalid
  Solution: 
  - Check token format (Bearer <token>)
  - Token expires after 1 day
  - Verify JWT_SECRET in .env

Problem: Test hangs or times out
  Solution:
  - Ensure backend is running (for test_real_api.js)
  - Check network connectivity
  - Increase timeout in test file
